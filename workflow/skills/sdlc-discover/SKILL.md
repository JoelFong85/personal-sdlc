# Discover

Read [the contract](../sdlc-orchestrator/references/artifact-contract.md). Inspect supplied requirements first, then relevant project guidance/code. Reuse valid discoveries instead of repeatedly exploring the repository.

Distinguish observed facts, user requirements, unverified historical claims, and proposals. Establish scope boundaries, existing behavior, dependencies, constraints, and high-impact unknowns. Propose focused requirement additions without replacing user intent.

Persist useful open questions in requirements.md and architecture context in the plan when needed; do not create a discovery report by default. Return concise known facts, unknowns, paths, and recommended next action. No implementation, approval, lifecycle writes, or external mutations.
