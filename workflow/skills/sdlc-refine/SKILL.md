# Refine

Read [the contract](../sdlc-orchestrator/references/artifact-contract.md). Check requirements for contradictions, scope overlap, vague behavior, missing relevant failure cases, and material tradeoffs. Ask a small batch of high-impact questions with recommendations and consequences; do not require exhaustive interviews for trivial work.

If delegated, return questions to the main session rather than inventing answers. Continue independent analysis while answers are pending. Preserve user intent and unresolved assumptions. Help define stable requirement IDs, observable acceptance criteria, exclusions, and decision rationale.

Return an approval-ready summary, changed artifacts, and unresolved questions. The orchestrator obtains and records explicit requirements approval. Do not write workflow state/history or proceed past unresolved material product decisions.
